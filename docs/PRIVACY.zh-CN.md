# 隐私政策 — Promptary

**最后更新:2026-09-15**

Promptary 是一个把图片反推成 AI 绘画提示词、并帮你管理这些收藏的 Chrome 扩展。本政策说明你的数据究竟经历了什么。

一句话版本:

- **你的收藏库只存在你自己电脑上。** 保存的图片、提示词、标签、分类,永远不会上传给我们。
- **图片怎么送到模型,取决于你用哪条渠道。** 用自己的 API Key,图片从浏览器直连你选的服务;用官方免费额度,则会经我们的一台中转服务器转发 —— 但我们不留存。
- 没有账号、没有埋点、没有遥测,不做任何形式的追踪。

---

## 一、两条渠道,两条路径

Promptary 有两条到达模型的路径,它们的隐私含义不同。你在**设置 → 模型服务**里选择。

| | 自己的 API Key | 官方免费渠道 |
| --- | --- | --- |
| 模型服务由谁提供 | 你自己选(DeepSeek、OpenAI、OpenRouter、自建服务…) | 我们,用的是 DeepSeek 的模型 |
| 图片发往哪里 | 从你的浏览器直连那家服务 | 经我们的一台中转服务器 |
| 我们能看到什么 | 什么都看不到,请求根本不经过我们 | 请求经过,但不留存 |
| 需要注册吗 | 不需要 | 不需要 —— 设备标识在本地随机生成 |
| 每日次数 | 无限制 | 有(每天几次) |

官方渠道存在的意义,是让你不必先去注册一个模型服务就能试用 Promptary。**如果你不希望任何东西经过我们,用自己的 API Key 就好** —— 那条路完全直连,和以前一模一样。

## 二、我们绝不收集的东西

无论你用哪条渠道,我们都不收集:

- 个人信息(姓名、邮箱、地址、电话)
- 账号凭据(因为没有账号)
- 浏览历史,或你访问过哪些页面的任何记录
- 你收藏的图片、提示词、标签、分类
- 你反推过哪些图、什么时候反推的
- 使用统计、崩溃报告、任何埋点事件

不存在任何形式的追踪。

## 三、存了什么,存在哪

Promptary 保存的所有东西都留在你自己的电脑上:

| 数据 | 存放位置 | 说明 |
| --- | --- | --- |
| 收藏的图片、提示词、标签、分类 | 浏览器本地 IndexedDB | 不上传到任何地方 |
| 你的 API Key 与模型设置 | `chrome.storage.local` | 与收藏库分开存放 |
| 界面偏好 | `chrome.storage.local` | 主题、语言等 |

**导出的备份里永远不含 API Key** —— 因为设置与业务数据是刻意分开存储的。

删除条目会先进回收站;清空回收站才真正抹掉。卸载扩展会清掉以上全部,因为它们本来就只存在于扩展自己的存储里。

## 四、数据什么时候离开你的设备

### 4.1 用自己的 API Key 时

> **当你让 Promptary 反推一张图片**,这张图会被发往你**自己**在设置里配置的那个模型服务。

Promptary 支持任何 OpenAI 兼容的接口。地址、API Key、模型名都由你提供。

- 图片**从你的浏览器直接发往你选择的服务**,不经过我们。
- **那家服务商的隐私政策决定这张图的命运。** 如果你指向的是第三方 API,请自行查阅它的条款。
- 如果你指向的是自己搭建的服务,那就完全不涉及第三方。

### 4.2 用官方免费渠道时

反推图片会把请求发到我们的一台中转服务器,由它转发给 DeepSeek 并取回结果。这台服务器具体记录什么、不记录什么,见第五节。

### 4.3 图片的传输方式(两条渠道都一样)

默认情况下,Promptary 先把图片的公网地址交给模型服务,由它自己去取;取不到时(比如站点做了防盗链),再下载到本地转成 base64 上传。你可以在设置里强制指定其中一种。

注意:走「地址直传」时,**图片本身我们一个字节都不经手** —— 经过的只是它的网址,真正的图片字节由模型服务自己去原站点拉取。

## 五、官方免费渠道的具体说明

这一节只在你使用免费额度时适用。用自己的 API Key 的话,整节都与你无关。

**中转服务器做什么**

检查你今天的剩余次数,把请求转发给 DeepSeek,再把答案传回来。这就是它的全部工作。

**它记录什么**

| 记录内容 | 用途 | 保留时间 |
| --- | --- | --- |
| 一个匿名的设备标识(浏览器生成的随机 UUID) | 统计你今天反推了几张 | 7 天,之后自动删除 |
| 当天请求次数 | 每日额度 | 7 天 |

这个设备标识是随机的,不从你的任何信息推导而来,也不与任何账号关联 —— 因为根本没有账号。重装扩展会生成一个新的。

**它不记录什么**

- **你的图片。** 转发完即丢,不写盘。
- **你的提示词,或为你生成的提示词。**
- **你的 IP 地址。** 为防止滥用,内存里会短暂持有一个请求计数器;它从不写盘,服务一重启就清空。
- **你反推过哪些图。** 请求不做日志。
- **你访问过哪些页面。** 扩展只发送图片本身 —— 不发送页面地址,也不发送页面标题。你在哪个网站上看图,这个信息不会离开你的浏览器。

**安全与保留**

请求经 HTTPS 传输。唯一被持久化的数据就是上面那张配额表,按 7 天滚动删除。

## 六、权限用途

Chrome 会提示这个扩展申请的权限。逐条说明它们各自用来做什么:

| 权限 | Promptary 为什么需要它 |
| --- | --- |
| `contextMenus` | 添加右键菜单项(「反推这张图的提示词」「收藏这张图」等)。这是你使用扩展的主要入口。 |
| `storage` | 在本地保存你的设置和 API Key。 |
| `sidePanel` | 让主界面显示在浏览器的侧边栏里。 |
| `activeTab` | 在你主动触发操作时读取当前标签页的地址与标题,好让收藏项能记下来源。只在你操作时使用。 |
| `scripting` | 如果你在扩展安装之前就已经打开的页面上用右键反推,页面上还没有内容脚本。这个权限让它补注入一次,使操作仍然可用。 |
| `<all_urls>` | **见下。** |

### 为什么需要 `<all_urls>`

Promptary 要在任何网站上都能用,因为你可能在任何地方遇到值得参考的图 —— 图站、社交信息流、博客、商店。

具体来说,这个权限允许 Promptary:

- 读取你右键点击的那张图,以便反推
- 读取当前页面的图片列表,好让你挑选
- 在你点「注入到页面」时,往页面上的输入框写入文字,把提示词送进生图工具
- 在图片上显示悬停按钮

它**不允许** Promptary 在后台做任何事。Promptary 从不读取你没有主动操作过的页面,也从不自行把页面内容发往任何地方。以上所有行为都只发生在你点击之后。

用官方渠道时,唯一的出网目的地是我们的中转服务器;用自己的 API Key 时,唯一的出网目的地是你自己配置的那个接口。

## 七、第三方服务

Promptary 自身不集成任何第三方统计、广告或追踪服务。

反推图片时可能涉及两个第三方,取决于你的渠道:

- **用自己的 API Key 时**:你配置的那个模型服务。它不是我们的次级处理者 —— 我们与它没有关系,也不从它那里收到任何东西。请另行查阅它的隐私政策。
- **用官方渠道时**:DeepSeek,它替我们完成实际的图片分析。第五节描述的中转服务器是我们的;DeepSeek 从它那里收到请求,并受 DeepSeek 自己的条款约束。

## 八、数据的分享与出售

我们不出售、不分享、不出租、不交换你的数据。用自己的 API Key 时我们根本收不到;用官方渠道时我们只是转发而不留存,且除「产出你要的那条答案」之外不作任何用途。

## 九、你对数据的控制

- **导出**:设置 → 数据与存储,可以把全部内容导出成 JSON 文件,或导出到文件夹(图片落成独立文件)。导出不含 API Key。
- **导入**:可以导入备份;同 id 的条目会跳过,不会覆盖。
- **删除**:删除条目会先进回收站,清空回收站则永久移除。卸载扩展会清掉一切。
- **完全不经过我们的服务器**:在设置里把模型服务换成自己的 API Key 即可。

## 十、儿童隐私

Promptary 不面向儿童,也不收集任何人的个人信息,包括 13 岁以下的儿童。
