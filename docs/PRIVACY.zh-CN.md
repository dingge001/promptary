# 隐私政策 — Promptary

**最后更新:2026-09-14**

Promptary 是一个把图片逆向成 AI 绘画提示词、并帮你管理这些收藏的 Chrome 扩展。本政策说明你的数据究竟发生了什么。

一句话概括:**我们不收集、不传输、也不在我们控制的任何服务器上存储你的任何数据。** 没有 Promptary 账号,没有埋点,没有遥测。

---

## 一、我们不收集什么

Promptary 没有后端服务器。我们没有任何接收你数据的服务。具体来说,我们不收集:

- 个人信息(姓名、邮箱、地址、电话)
- 账号凭据(根本没有账号)
- 浏览历史
- 你分析的图片
- 你保存的提示词
- 使用统计、崩溃报告、分析事件

没有任何形式的追踪。

## 二、存了什么,存在哪

Promptary 保存的一切都在你自己的电脑上:

| 数据 | 存储位置 | 说明 |
| --- | --- | --- |
| 收藏的图片、提示词、标签、分类 | 浏览器本地 IndexedDB | 不上传到任何地方 |
| API 密钥与模型设置 | `chrome.storage.local` | 与收藏内容分开存放 |
| 界面偏好 | `chrome.storage.local` | 主题、语言等 |

**导出的备份里不包含 API 密钥**——因为设置与库数据在设计上就是分离存储的。

删除内容会先进入扩展内的回收站;清空回收站才会永久移除。卸载扩展会删除上述全部数据,因为它们都存在于扩展自己的存储空间里。

## 三、数据什么时候会离开你的设备

只有一种情况,而且**每一次都由你主动触发**:

> **当你让 Promptary 分析一张图片时**,这张图片会被发送到**你自己在设置里配置**的 AI 模型服务。

Promptary 支持任何 OpenAI 兼容接口。接口地址、API 密钥、模型名都由你填写,常见选择包括 DeepSeek、OpenAI、OpenRouter,或你自己搭建的服务。

这意味着:

- 图片**从你的浏览器直接发往你选择的服务**,不经过我们——我们根本没有服务器可以经手。
- **该服务商自己的隐私政策约束着这张图后续会怎样。**如果你指向的是第三方 API,请另行查阅对方的条款。
- 如果你指向的是自己搭建的服务,那就完全没有第三方参与。
- 模型返回的提示词文本按上文所述存在本地。

默认情况下,Promptary 会先把图片的公网地址交给模型服务,让服务端自己去取。如果取不到(比如站点有防盗链),再改为本地下载后以 base64 上传。你可以在设置里强制指定其中一种。

**扩展自身不发起任何网络请求**,只与你配置的那个接口通信。

## 四、权限用途

Chrome 会提示这个扩展申请的权限。逐条说明它们各自用来做什么:

| 权限 | 用途 |
| --- | --- |
| `contextMenus` | 添加右键菜单项(「反推这张图的提示词」「收藏这张图」等)。这是你使用扩展的主要入口。 |
| `storage` | 在本地保存你的设置和 API 密钥。 |
| `sidePanel` | 在浏览器侧边栏承载主界面。 |
| `activeTab` | 在你触发操作时读取当前标签页的地址和标题,让收藏项能记录来源。仅在你主动操作时使用。 |
| `scripting` | 如果你在扩展安装**之前**就已打开的页面上使用右键反推,页面里还没有内容脚本。此权限用于动态补注入一次,让操作不至于失败。 |
| `<all_urls>` | **见下。** |

### 为什么需要 `<all_urls>`

Promptary 要能在任何网站上工作,因为你可能在任何地方遇到值得参考的图——画师站、社交信息流、博客、商店。

具体而言,这个权限允许 Promptary:

- 读取你右键点击的那张图,以便分析
- 读取当前页面的图片列表,供你挑选
- 在你点击「注入到页面」时,把提示词写进页面上的输入框,以便送到生图工具
- 在图片上显示悬停按钮

它**不允许** Promptary 在后台做任何事。Promptary 不会读取你未曾主动操作的页面,也不会自行把页面内容发往任何地方。上述行为全部只在你点击时发生,而唯一的出网目标是你自己配置的接口。

## 五、第三方服务

Promptary 自身不接入任何第三方分析、广告或追踪服务。

你配置的 AI 模型服务是你自己选择的第三方,不是我们的转包方——我们与它没有任何关系,也不从它那里接收任何东西。请单独查阅该服务商的隐私政策。

## 六、数据共享与出售

我们不共享、出售、出租或交换你的数据,因为我们从一开始就收不到。

## 七、你对数据的控制

- **导出**:设置 → 数据与存储,可以把全部内容导出为 JSON 文件,或导出到一个文件夹(图片落成独立文件)。导出内容不含 API 密钥。
- **导入**:可导入备份;同 ID 的条目会被跳过而不是覆盖。
- **删除**:删除条目会先进回收站,清空回收站才永久移除。卸载扩展会清除全部。

## 八、儿童隐私

Promptary 不面向儿童,也不向任何人(包括 13 岁以下儿童)收集个人信息。
